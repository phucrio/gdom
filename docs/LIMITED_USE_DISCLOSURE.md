# Google API Limited Use disclosure

Display this disclosure in the account-connection and full-Drive-scope confirmation flows, and link to it from the Privacy Policy:

> GDOM's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The confirmation flow must also state why the requested scope is required, what Drive metadata is accessed, that data remains local, and that no Drive data is sent to analytics or AI.
